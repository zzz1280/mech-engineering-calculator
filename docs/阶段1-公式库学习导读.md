## 二、三个底层决策（这是本阶段真正要学的东西）

### 决策 1：单位只在边界换算，内部一律 SI

`calcs/` 里所有函数**只接受 SI 单位**（m、N、Pa、m⁴），唯一的例外是 `fits.py` 用 μm（公差行业惯例）和 `bolt_group.py` 用 mm、N·mm（机械设计教材惯例）。

**为什么**：工程计算 90% 的 bug 来自单位混乱。如果每个函数都接受"任意单位再自己猜"，迟早出现"E 用 GPa 代进了 Pa 的公式"这种错，而且算出来的数还**看起来挺合理**。统一内部单位制后，这类错误只可能发生在最外层，一眼可见。

**代价**：Web 阶段（阶段 2）必须在表单层做转换并写清楚单位标签。这笔账划算。

### 决策 2：符号约定写死在 docstring 里

梁的挠度取**向下为正**。材料力学里向上/向下两种写法都在用，混用就差一个负号，而负号错误是"符号错了但数值对了"——最阴险的一类 bug。

所以 `beam.py` 开头就把约定写死，且每个函数 docstring 再写一遍。

### 决策 3：能查表就查表，不用公式"推导"标准值

这一条是阶段 1 最反直觉的收获，值得单独讲：

拟合公差基本偏差时，ISO 286 给了经验公式（如 `d: es = −16·D^0.44`）。但拿 φ30 试算：

```
几何平均 D = √(18×30) = 23.24 mm
公式值     = −16 × 23.24^0.44 = −63.86 μm
标准表值   = −65 μm            ← GB/T 1800.2
差 1.14 μm
```

1 微米对"理解公式"无所谓，对标在图纸上的公差就是**错的值**。所以 `fits.py` 内置标准表值，公式只用来理解、不用来出数。

推论（写进代码原则了）：**没有可靠来源的数值，宁可报错也不给近似值**。所以 `fits.py` 对 a、b、j、t、u 等代号直接抛 `ValueError` 而不是返回"差不多的数"。

## 三、四个模块各自要盯住的概念

### 1. beam.py —— 叠加法是本模块的灵魂

教材表里每种工况给一个公式，照抄会产生十几个分支。这里改成：**写"任意位置集中载荷"和"全跨均布载荷"两个通解，然后相加**。

```python
# 挠度 = 集中载荷贡献 + 均布载荷贡献
y_point += P * b * x * (L**2 - b**2 - x**2) / (6.0 * L * EI)   # 集中载荷
y_point += q * x * (L**3 - 2.0*L*x**2 + x**3) / (24.0 * EI)    # 均布载荷
```

代价是**得自己找最大值点**（教材表直接给了 δ_max）。所以代码里同时算了「闭式解」和「数值扫描」两套结果，并断言二者吻合（容差 0.5%）：

```python
if abs(y_formula - y_num) > max(abs(y_formula) * 5e-3, 1e-12):
    raise AssertionError("内部自检失败：闭式解与数值扫描不一致")
```

**这是本模块最好的学习点**：用两种独立途径算同一个量，让程序自己验证自己。后面做阶段 3 画挠度曲线时，这个采样点数组可以直接喂给 Matplotlib。

### 2. bolt_group.py —— 到"翻转轴线"的距离，不是到形心

倾覆力矩公式 `F_i = M·L_i / ΣL_j²` 里的 `L_i` 是**螺栓轴线到翻转轴线 O-O 的距离**，不是到螺栓组形心的距离。这是教材中最容易和"受扭矩"混淆的地方。

本阶段在这里真的踩了个坑，见第四节。

### 3. bearing.py —— 两个 Y

`F_a/F_r ≤ e` 时标准规定轴向载荷影响可忽略，取 `Y = 0`。但从 `F_a/C_0r` 查表插值出来的 `Y` 可能是 1.77。

**这两个 Y 是两回事**，代码里拆成 `Y`（实际代入的）和 `Y_table`（查表得到的）。混为一谈会让 P 算错一大截。

另外记住寿命的三次方律：**载荷减半，球轴承寿命变 8 倍**（`test_life_cube_law` 就是断言这件事）。

### 4. fits.py —— Δ 规则与"同名配合互换"

孔的基本偏差由同名轴偏差换算：

- `A~H`：`EI = −es(同名轴)`（不加 Δ）
- `J~ZC`：`ES = −ei(同名轴) + Δ`，其中 `Δ = IT_n − IT_(n−1)`

为什么 J~ZC 要加 Δ？为了让**基孔制 H7/k6 与基轴制 K7/h6 的极限间隙/过盈完全相同**。

验证（φ30，单位 μm）：

| | 孔 | 轴 | 最大间隙 | 最小间隙 |
|---|---|---|---|---|
| H7/k6 | 0 / +21 | +2 / +15 | 21−2 = 19 | 0−15 = −15 |
| K7/h6 | +6 / −15 | 0 / −13 | 6+13 = 19 ✓ | −15−0 = −15 ✓ |

如果 K7 忘了加 Δ，会算成 ES = −2、EI = −23，这对配合就对不上了。这条已固化为测试 `test_same_name_fit_equivalence`。

## 四、本阶段踩到的两个坑（已经修好并写成测试）

### 坑 1：圆形法兰闭式解会高估 15.5%

我第一版写了 `F_max = 4M/(z·D)`，隐含假设"有螺栓正好落在离翻转轴线最远处（L = r）"。

- `z = 4`：θ = 0°, 90°, 180°, 270° → 确实有螺栓在 90°，假设成立 ✓
- `z = 6`：θ = 0°, 60°, 120°, … → 最远只到 `r·sin60° = 0.866r`，假设**不成立**

z=6、D=200、M=5×10⁵ N·mm 时：正确值 1443.38 N，错误公式给 1666.67 N。

修法是改用实测 `L_max` 代入，并加了断言 `!= 4M/(zD)`，防止以后有人改回去。

> **教训**：闭式解很美，但每个闭式都有适用条件。写之前先问"这个公式假设了什么"。

### 坑 2：Y 的语义混淆

见第三节第 3 点。第一版只返回一个 `Y`，测试里期望 1.77 而代码给 0——**测试是对的，代码语义不清**。拆成 `Y` / `Y_table` 后清楚多了。

> **教训**：当一个测试"失败"时，先判断是代码错还是期望值错。这次两条都出现过（坑 1 是我测试期望值照抄了错误公式）。

## 六、本阶段遗留问题（阶段 2 之前要解决）

1. **公差代号覆盖不全**：a、b、j、t、u、v、x、y、z、za、zb、zc 未内置，>80 mm 的 r/s 也无可靠数据。如果要支持，需要按 GB/T 1800.2 原表补数据（必须逐格核对，不能推）。
2. **`beam.py` 的载荷方向**目前只支持向下（P、q 非负）。实际工程中可能有向上的载荷，阶段 2 前确认要不要放开。
3. **轴承的 f_t / f_p 是老制**（教材口径）。ISO 281:2007 起改用 a_ISO 修正。README 里必须写明这一点，否则懂行的人会挑刺。
4. **梁的适用条件没有校验**：材料力学公式默认小变形、线弹性、平面弯曲。任务书"加分项"要求对超出适用范围给提示（比如长径比、挠度超过梁高的 1/10 时），阶段 2 或 3 补。
